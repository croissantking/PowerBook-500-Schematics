# Macintosh PowerBook 500 Series CPU Card Schematics

The PowerBook 500 Series is a very popular laptop with hobbyists. Lately I have been tinkering a lot with mine. Unfortunately no schematics are available which limits repair and modding potential. In an effort to remedy this, I studied a CPU card with a multimeter and drew up schematics in KiCad.

The CPU card is essentially identical across all five models: the 520, 520c, 540, 540c and 550.
